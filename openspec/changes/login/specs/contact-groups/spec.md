# Spec Delta

## MODIFIED Requirements

### Requirement: Создание группы

Система SHALL позволять владельцу создавать группы с любым названием. Название
группы уникально в пределах одного владельца, без учёта регистра и различия
«е»/«ё»; ведущие и конечные пробелы отбрасываются. У разных пользователей могут
быть одноимённые группы (например, у каждого своя «Друзья»). Группу можно создать
«на лету» в момент назначения контакту, а также явно на странице управления
группами.

Поле назначения группы SHALL по мере ввода подсказывать подходящие существующие
группы владельца; если введённого названия у него ещё нет, SHALL предлагать создать
его. Отдельной кнопки «добавить» для этого не требуется.

#### Scenario: Новая группа создаётся при назначении

- **WHEN** владелец в карточке контакта вводит в поле добавления название «Аналитики», которого у него ещё нет
- **THEN** создаётся группа «Аналитики» этого владельца
- **AND** она сразу назначается этому контакту

#### Scenario: Группа создана на странице управления

- **WHEN** владелец на странице управления группами создаёт группу с новым названием
- **THEN** группа появляется в списке его групп
- **AND** её можно назначать контактам и выбирать в фильтре

#### Scenario: Существующее название не плодит дубликат

- **WHEN** владелец вводит название группы, которая у него уже есть (пусть и в другом регистре, например «теннис» при существующей «Теннис»)
- **THEN** новая группа не создаётся
- **AND** контакту назначается уже существующая группа этого владельца

#### Scenario: У другого пользователя может быть группа с тем же названием

- **WHEN** у пользователя A есть группа «Друзья» и пользователь B создаёт у себя группу «Друзья»
- **THEN** у B создаётся собственная группа «Друзья»
- **AND** группы A и B независимы

#### Scenario: Пустое название не создаёт группу

- **WHEN** владелец пытается добавить группу с пустым названием или из одних пробелов
- **THEN** группа не создаётся и контакту ничего не назначается
